Todays Lab: Login & Logout

Build a simple Django app that lets users sign in and sign out, and protects a “dashboard” page so only authenticated users can view it.

Required Challenge:
  • Login page – A form where users enter username & password.
  • Logout link – So logged‑in users can safely sign out.
  • Dashboard page – Only visible to users who are logged in; all others are redirected to the login page.
Bonus Challenge:
  • Add “Remember me” (session persistence) checkbox.
  • Display the user’s last login time on the dashboard.
  • Use Django’s messages framework for success/error notifications.

Todays Lab: Registrations

Build a registration system where users can sign up with a username, email, password, and provide additional profile information like a bio and profile picture. Create two forms: A form for basic user details (username, email, password). A second form for extended profile info (bio + optional profile picture). Set up a view to handle the following: Display both forms on one page. Process submitted data. Validate both forms. Hash the password before saving the user. Link the profile to the user (one-to-one relationship). Handle image uploads if a profile picture is submitted. Create a template that: Displays both forms on the same page. Shows success message after successful registration.
